## 设计原则

- 统一：品牌色、字体、卡片、按钮、5 个分区和全部功能。
- 分化：iPad 用多列网格/两栏；iPhone 仍为单列 + 底部标签栏。
- 不新增功能，不复制竞品视觉；只重排现有内容。
- 图标使用 SF Symbols 等价线性图标；实现时用 `Image(systemName:)`。

## 备注

- 学习/训练页面下方仍会有滚动余量；视觉稿没有为了填满而发明内容。
- 曲目页的 PDF 封面为示意；实现时用 PDF 首页缩略图。
- 需要横屏版本时，在 1024→1366 宽度变化下把 2 列/3 列保持，谱面区优先。
- HTML/CSS 源文件在 `src/`，可改文案/间距后重渲染。
