# Brand story / 品牌来历

## dorewio.

**do–re** 是唱名的起点，也是这个产品第一课的内容（音名、唱名、空弦与第一把位）。
**w** 由两个 **V** 组成，分别代表 **Violin（小提琴）** 和 **Viola（中提琴）**——弦乐器是这个产品的核心。
词尾的句点 `dorewio.` 是字标（wordmark）的一部分。

## 起点：揉弦（2026-08-13 ~ 08-15）

最初的需求只有一句：「我想做一个小提琴软件」。

当时最想解决、也最缺现成工具的是 **揉弦（vibrato）练习**：
- 揉弦是否均匀、幅度是否合适、速度是否稳定；
- 揉弦是否围绕目标音高中心，还是整体偏高/偏低；
- 以及“喜欢的歌找不到谱，能不能把旋律扒下来”。

第一个原型因此被命名为 **VibratoCoach**（Vibrato + Coach，揉弦教练），第一版只做“选择目标音 → 麦克风实时音高 → 揉弦速度/幅度/稳定度分析 → 中文反馈”。当时也参考了 Ray Chen 的 Tonic：Tonic 更像“有人陪你练”，而我们要做“告诉你具体该怎么练”的技术教练。

## 从揉弦到完整练习 App

之后功能逐步扩展：调音、音准曲线、运弓、节奏、识谱、第一把位指板、空听辨、录音/音频导入、慢放循环、单旋律扒谱、乐谱导入（MusicXML/MXL）与跟奏、每日计划与练习记录。

用户可见名称也换了几次：
- 2026-08-15：小提琴陪练
- 2026-10-27：小提琴自学（App Store 记录名）
- 2026-11-12：**dorewio.**

## 技术遗留：Bundle ID

App Store 记录创建时使用的 Bundle ID 是 `com.archintera.VibratoCoach`（来自最早的 VibratoCoach 工程），App Store Connect 创建后无法更改。因此：
- **工程/仓库/品牌**统一为 `dorewio`；
- **Bundle ID 永久保留 `com.archintera.VibratoCoach`**，不要改动，否则会脱离现有 App Store 记录。

这也是为什么仓库历史里会同时看到 `VibratoCoach`（技术遗留）和 `dorewio`（产品品牌）两个名字。
