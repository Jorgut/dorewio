## 本机环境要点（DeepSeek Harness）

- 网络：GitHub 直连不可用，需系统代理 `127.0.0.1:7897`：`export HTTPS_PROXY=http://127.0.0.1:7897 HTTP_PROXY=http://127.0.0.1:7897`。
- **`git push` 会被代理层中断**（receive-pack 挂起）。改用 GitHub Git Data API 推送分支 + 建 PR：
  `python3 .tmp/push_branch_via_api.py <branch> main <commit-msg-file> --pr-title "…" --pr-body-file <body-file>`
  （脚本读取 `gh auth token`，用 `gh api` 创建 blob/tree/commit/ref/PR；成功后本地分支已同步为远端 commit。若 `.tmp` 被清理，按同思路用 `gh api repos/Jorgut/dorewio/git/...` 重建。）
- 测试（沙箱必须重定向 TMPDIR/模块缓存）：
  ```
  TMPDIR="$PWD/.tmp/TMPDIR" CLANG_MODULE_CACHE_PATH="$PWD/.tmp/clang-module-cache" \
    swift test --scratch-path .build-core --cache-path .swiftpm-core --disable-sandbox
  ```
- 构建：会话文件沙箱下 SwiftUI 宏插件会报 `SwiftUIMacros.* malformed response` / `sandbox_apply`，xcodebuild 需放宽文件访问（danger-full-access）才能跑；命令：
  ```
  xcodebuild -project dorewio.xcodeproj -scheme dorewio \
    -destination 'generic/platform=iOS Simulator' -derivedDataPath .deriveddata \
    CODE_SIGNING_ALLOWED=NO build
  ```

## 给网页端 Agent 的约定（来自仓库 AGENTS.md）

- 产品 **dorewio.**，原生 iOS SwiftUI；不要换成 Web/RN/Flutter。
- 音乐准确性：F5 = F natural（MIDI 77）/ E 弦低一指；F♯5 是另一音；空弦 G3 D4 A4 E5；固定 Do 唱名要明确标注。
- 指板图：琴头/弦枕在上、琴身在下，G/D/A/E 从左到右；圆点是教学近似，不是琴格。
- 音频全部为合成音（课程参考音正弦；乐谱播放为带泛音合成），没有采样琴声。
