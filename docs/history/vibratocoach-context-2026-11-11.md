# VibratoCoach 项目状态

更新时间：2026-11-11（Asia/Almaty）

## 当前目标

构建一款 iPhone 小提琴自学 App。产品必须在用户有琴和没有琴时都能提供有效学习内容，而不只是调音、检测和练习记录工具。

## 已确认的产品方向

- 核心定位：有琴 / 无琴双模式的小提琴自学系统。
- 核心闭环：理解 → 听辨 → 无琴练习 → 实琴验证 → 针对错误复习。
- 陪练社区不是当前优先级，可在后期作为增强功能。
- 没有琴时的核心内容：识谱、虚拟指板、空弦与音高听辨、节奏训练、曲目预习。
- 有琴时的核心内容：调音、音准轨迹、节奏与运弓反馈、揉弦分析、录音对比、曲目逐句验证。
- 曲目功能的目标不是只生成一张谱，而是把用户喜欢但找不到谱的歌曲转换成初学者能学习的简化旋律、指法和逐句任务。
- 自动扒谱结果必须允许修正并表达识别可信度，不能把不可靠结果伪装成准确乐谱。
- 第一版不采用手持手机模拟琴弓或揉弦的训练方式，避免手机重量与握法强化错误动作。

## 建议信息架构

1. 今天：选择有琴 / 无琴，生成每日短课程。
2. 学习：结构化课程、识谱、指板和演奏知识。
3. 训练：听音、节奏及实际演奏检测。
4. 曲目：导入歌曲、旋律提取、简化、分句练习。
5. 进度：按识谱、听音、节奏、指板、音准等技能展示掌握程度。
