## 2. 我们和别人不一样的地方（差异化）

### 一句话定位

> **dorewio 是“离线、自带乐谱的小提琴技术教练”，不是又一个订阅曲库。**

### 五个真实差异点

1. **自己的谱，而不是别人的曲库**
   - 我们支持导入 MusicXML / MXL，直接按谱发声、显示弦与指法、变速/循环/节拍器/预备拍。
   - 大厂（Trala/tonestro/一起练琴/来音）主要让你用它们的曲库；你的谱进不去，或者只能看不能跟奏。
   - 1.1 计划 PDF 只读查看，1.2 计划 PDF→MusicXML（OMR），进一步强化“任何谱都能带进来”。

2. **完全离线、无账号、数据本地**
   - 练习记录/录音/乐谱全部在本机；无服务器、无登录、无广告/统计 SDK。
   - 对“琴房没网/不想注册/在意隐私/家长不想给孩子开账号”的人是硬需求。
   - 竞品几乎都要求账号+联网+订阅。

3. **技术教练，而不是内容播放器**
   - 调音、音准、揉弦、运弓、节奏、识谱、第一把位指板、听辨，都是本地实时分析。
   - 大厂强在课程内容；我们强在“把动作做对”的即时反馈，且离线可用。

4. **新手友好的教学结构**
   - 音名/唱名/空弦/第一把位一条线；C2 真实琴颈方向、空弦+1 指圆点、三步引导。
   - 竞品的新手引导通常服务于“卖订阅”，我们的引导服务于“今天就能拉出第一句”。

5. **一次买断，不订阅**
   - 没有服务器/内容运营成本，订阅缺乏“持续服务”的合理性；买断更符合工具属性，也更容易形成口碑。
   - 对用户：¥68 一次性 vs ¥699/年，决策成本低得多。

### 我们的弱点（要诚实）

- 没有大曲库、没有 AI 伴奏、没有老师点评、没有社区
- 目前只支持单声部 MusicXML/MXL；PDF 还不能跟奏
- 只有 iOS；中国区还要 ICP 豁免/备案
- 品牌新、没有内容营销积累

**所以不要正面拼“曲库/课程/陪练”，要拼“离线 + 自带谱 + 买断 + 技术反馈”。**

## 3. 两条付费模式对比

| | A. 付费下载 | B. 免费下载 + Pro 买断（推荐） |
|---|---|---|
| 价格 | ¥38–48 | 免费；Pro ¥68（早鸟 ¥48） |
| 优点 | 每次下载都有收入；过滤非目标用户 | 免费获客/ASO/评价；先体验再付费；可做首发优惠 |
| 缺点 | 没有试用，转化低；排名/曝光吃亏；退款/差评风险；无法做免费工具入口 | 需要设计免费/Pro 边界；转化率约 1–3% |
| 适合 | 强品牌/强刚需小工具 | 新品牌、需要口碑和评价、工具体验型产品 |

**订阅（C）为什么首发不做：**

- 离线 App 没有持续服务成本，订阅缺少“持续价值”，审核也更容易被问
- 年卡 ¥168–699 的竞品都有持续内容/AI/陪练；我们没有
- 订阅的退款、取消、续订运营对小团队是负担
- 等以后有“每月新曲库/AI 伴奏/在线陪练”再考虑订阅或曲库包

### 推荐：B（免费 + 买断）

免费层（获客 + 激活）：
- 调音器、节拍器
- dorewio 第一课
- 每日计划
- 基础识谱/节奏/指板/听辨（每模块前几组）

Pro 买断（¥68 一次性）：
- 全部训练模块（运弓、揉弦、进阶音准）
- **乐谱导入/跟奏**（MusicXML/MXL，变速/循环/节拍器/预备拍）
- 音频导入 + 单旋律扒谱
- 完整练习统计/导出

付费墙触发点：
- 点击「导入乐谱」时
- 完成第 2–3 次练习后
- 点击进阶训练时

## 4. 起步定价建议

### 推荐价格

- **中国区：Pro 终身 ¥68**
- **首发早鸟：¥48**（上线前 2 周或前 500 名，用限时降价/优惠码）
- **海外：$9.99**
- 免费下载，无广告

### 定价依据

- 锚点 1：一节线下小提琴课 ¥200–400 → ¥68 ≈ 1/4–1/3 节课
- 锚点 2：竞品订阅 ¥368–699/年 → ¥68 一次性明显更低
- 锚点 3：小工具买断 €9.99–14.99（约 ¥80–115）→ ¥68 在区间内
- 锚点 4：教育类年订阅中位价约 $44.99（约 ¥320）→ 买断 ¥68 有价格优势

### 价格测试

- 首发先 ¥68；用早鸟 ¥48 冲评价和口碑
- 1–2 个月后测试 ¥88（或 ¥48 vs ¥68 vs ¥88 的 A/B/分地区）
- 看 **D30/D60 每安装收入**，不要只看当天转化

### 收入粗算（Apple 15% 抽成后）

| 月安装 | 1% 付费 | 2% 付费 | 3% 付费 |
|---|---|---|---|
| 10,000 | ¥5,780 | ¥11,560 | ¥17,340 |
| 50,000 | ¥28,900 | ¥57,800 | ¥86,700 |
| 100,000 | ¥57,800 | ¥115,600 | ¥173,400 |

> 关键不是定价，是留存和转化；先把 D7 ≥20%、D30 ≥8%、安装→付费 ≥1.5% 跑出来，再投广告。

## 5. 商业闭环（针对 dorewio）

```
① 获客
   App Store ASO：小提琴/调音/自学/识谱/乐谱/陪练
   短视频：60 秒第一课、导入喜欢的歌直接跟奏、C2 指板
   家长群/老师推荐/教育 KOL；后续 Apple Search Ads

② 激活（首次 5 分钟）
   免费调音器即开即用 → 第一课（60 秒 aha）
   第二个 aha：导入一首自己的 MusicXML → 直接跟奏

③ 留存
   每日计划 + 连续天数 + 进度曲线
   每月新增 1–2 首示例谱（低成本内容）
   本地通知提醒；无账号也能保存

④ 变现
   免费层 → Pro 买断 ¥68（早鸟 ¥48）
   触发点：导入乐谱 / 进阶训练 / 第 2–3 次练习后
   恢复购买 + 无订阅说明

⑤ 口碑
   练习成果海报分享（微信/小红书）
   老师/家长推荐码；App Store 评分引导

⑥ 扩展
   曲目包（考级曲/流行歌简化谱，¥6–18/包）
   PDF 只读查看（1.1）→ PDF OMR（1.2）
   未来：AI 伴奏/教师端（再考虑订阅）
```

### 关键指标

- 激活率（完成第一课/调音）≥50%
- D7 留存 ≥20%，D30 ≥8%
- 安装→付费 1.5–3%
- 退款率 <3%
- 评分 ≥4.5

## 6. BizPeel（你说的 Beespear）能借鉴什么

BizPeel 公开库约 799 个线上产品，Education 类目 40 个，**没有小提琴/乐器学习 App**；它主要覆盖 SaaS、AI 工具、课程、模板。能借鉴的是“增长逻辑”，不是直接价格对标。

最接近的案例：

| 案例 | 数据 | 可借鉴 |
|---|---|---|
| **Verbi**（AI 语言 App） | $23.7K MRR；30 天 $22.7K | Freemium + 订阅 + 试用；App Store/内容获客；小团队可以做到 $20K+ MRR |
| **Speak Silq**（语言 App） | $10K–30K MRR | 靠 Instagram 合作展示获客，不是纯 ASO |
| **FrancoPass**（入籍考试 App） | <$10K | App Store + 短视频 + Google；单一明确场景 |
| **Tifox**（幼儿园练习册 App） | <$10K | 卖给老师（B2B2C），小工具也能收费 |
| **Codédex** | $50K–100K | 免费学习内容 → 订阅；内容驱动 |

**结论：**

- 小团队做窄场景 + 明确结果 + 内容/达人获客，可以做到 $10K–30K MRR
- 订阅适合“持续练习/内容”；买断适合“工具/一次性交付”
- BizPeel 没有音乐学习 App，说明这个细分在“线上产品库”里不拥挤，但也意味着没有现成模板，要靠 App Store 竞品和真实用户验证

## 7. 最终建议（一句话版）

**首发：免费下载 + Pro 买断 ¥68（早鸟 ¥48），不做订阅；差异化打“离线 + 自带乐谱 + 技术教练”。**

- 先靠免费调音器/第一课/示例谱获客
- 用“导入自己的谱”作为付费理由
- 跑通留存和转化后，再加曲目包/PDF/OMR，必要时再考虑订阅
- 中国区先申请 ICP 豁免，再开国区
